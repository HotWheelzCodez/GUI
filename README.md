# GUI
A simple and easy to use CSS inspired GUI library using Raylib in C++

# Building
For right now this project builds along-side your project, instead of compiling into a library file.
## Windows
To compile and run on Windows, simply use the `run.bat` file
```run.bat```
## Unix
To compile and run on Unix, simply use the `run.sh` file
```bash run.sh```
